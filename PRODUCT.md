# Untranslatable

A shared artwork people can wander through and build together. Make a mark,
leave it in the world, and return to discover what has grown around it.

Confirmed: one shared world, visitor creation and placement, open source,
the accepted collection's visual identity, concentrated scope, a beautiful and
calming space. It can develop into an audiovisual album: moving through the
world changes the sound. This first release is its visual foundation; album
audio and interactive sound are a later phase, once the music is supplied.
Primary flow: explore → make → publish in place → explore.
Durable contributions belong to server storage; transient drafts stay on the
visitor's device. Everyone sees the same contributions. No account/profile
system is requested. Visitors cannot modify another person's existing marks.

Platform: responsive web. Stack: Canvas2D, native controls, Web Request API,
Bun/SQLite or Cloudflare/D1. Keyboard, touch and reduced-motion support.
